# Roadmap — Arquiteto de Software com IA (2026–2027)

Site estático e interativo, pronto para GitHub Pages.

## Publicação

1. Crie um repositório público no seu GitHub, como `roadmap-arquiteto-ia`.
2. Adicione os arquivos `index.html` e `.nojekyll` na raiz da branch `main`.
3. Em **Settings > Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e salve.
4. Aguarde a implantação e use a URL informada pelo próprio GitHub em **Settings > Pages**.
5. No Notion, digite `/embed` e cole a URL publicada.

O site armazena o progresso localmente no navegador. Os dados **não** são sincronizados automaticamente entre dispositivos.

> Antes de publicar, revise o conteúdo: repositórios públicos e páginas do GitHub Pages podem ser acessados por qualquer pessoa.
